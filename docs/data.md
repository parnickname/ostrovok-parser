# Фаза 1. Данные (DS)

Общая картина и порядок работы — [README](../README.md). Формат снапшота и точки стыковки с бэкендом — [snapshot-format.md](snapshot-format.md).

## Вводная

- **Читать:** [snapshot-format.md](snapshot-format.md): CFC-3 (формат снапшота), CFC-5 (калибровка), «Файлы снапшота» и таблица статусов визы; источники, лицензии и что генерируем — реестр `data/sources.yaml` и публичная страница «Данные и их источники» на https://app.ostrovok.crssr.ru/docs/.
- **Стек:** Python 3.12, стандартная библиотека и `requests`; сторонние библиотеки — только если без них загрузчик не написать, версии в `data/requirements.txt`.
- **Зона:** `data/`. Go-код и `web/` не трогаем.
- **От кого зависишь:** ни от кого. Формат файлов задан спекой 0003, бэкенд читает то, что ты положишь в `data/snapshot/`.
- **Кто ждёт тебя:** бэкенд, только на подключение. До твоих наборов он работает на своём тестовом снапшоте, после мержа — переключается на твой (репозиторий бэкенда подключает папку `data/snapshot/`). Чем раньше смержены `02`, `03`, `04`, тем раньше агент начнёт работать на реальных направлениях.
- **Ветки:** от `main`.

## Что ты отдаёшь

| Набор | Подзадача | Кто читает |
|---|---|---|
| `countries.jsonl`, `visa.jsonl` | `02.1`, `02.2` | `catalog`: страны, визы, фильтр подбора |
| `cities.jsonl` | `04.1` | `catalog`: город отправления, привязка направлений |
| `airports.jsonl` | `04.2` | `transport`: авиа |
| `destinations.jsonl`, `climate.jsonl` | `03.1`–`03.4` | `catalog`: подбор и погода |
| `hotels.jsonl` | `05.1`, `05.2` | `lodging` провайдер `osm` |
| `routes.jsonl`, `stations.jsonl`, `rail_routes.jsonl` | `06.1`–`06.3` | `transport` |
| `calibration.jsonl` | `07.1`–`07.6` | синтетические цены всех провайдеров |
| `sources.yaml` | `01.4`, `08.1` | страница «Откуда данные» |

Обязательное для каждого набора: схема из CFC-3, стабильный `id`, `sources` с именами из `sources.yaml`, запись в `manifest.json`, `python3 data/validate.py` проходит.
